### Added

- Writing as a frame in the core, part A (A1357, B8 R13-R15, spec 33 §9a): the vocabulary kind `writing_medium` has seven carriers, from marks in the sand to a library, with names in DE/EN. `content/writing/media.json` (schema `writing-media`, placeholder values) gives per carrier the decay per day, extra loss per weather (rain wipes sand), tool properties, best legibility and capacity, plus what write and read need (ability, least level, least legibility, curiosity). `WritingSystem` keeps the text on an object (knowledge ref, carrier, author, tick, legibility) and wears it away; at 0 the text is gone and the object stays; a text goes with its object; saved (meta `writing`); out of the hash while empty, so golden hashes are unchanged. `IWeather` is the interface agreed with GW1 for the weather core (#19313). The actions write and read come with the ability register (A1372) and the knowledge store (A1400).
- Sound jobs in the AI service (D471 D7, B2530): handler `sound` with the MOSS worker (`tools/moss/worker.py` in the MOSS environment: bf16 and official VRAM management after D440; starting it loads the model, ending it frees the VRAM) or a deterministic mock without the model. Steps are raised to `min_steps`; every result is checked (length, level, silence, clipping) and retried with the next seed up to `seed_retries`; nothing usable = the job fails and the core falls back to the base library. Files by name pattern in `sound_output_dir`. Settings `sound_backend` (mock/moss) and the local MOSS paths (`GW_AI_*`).
- Sound of inventions (D471 D7) and the compute-night signal over HTTP: after an invention that needs a sound is built, the core sends a `sound` job (description and kind from the rule guard, seconds, steps and priority from `content/sound/generation.json`); the result file is kept with the invention (`InventionInfo.SoundFile`, hash and save game); on failure the invention has no sound of its own and the game uses the base library by description. `HttpJobPort.SetPhase` posts `phase-change` to `/phase` on a real change, `Resend` repeats it after a service restart.
- Sound of inventions (D471 D7) and the compute-night signal over HTTP: after an invention that needs a sound is built, the core sends a `sound` job (description and kind from the rule guard, seconds, steps and priority from `content/sound/generation.json`); the result file is kept with the invention (`InventionInfo.SoundFile`, hash and save game); on failure the invention has no sound of its own and the game uses the base library by description. `HttpJobPort.SetPhase` posts `phase-change` to `/phase` on a real change, `Resend` repeats it after a service restart. ### Changed

- Chronicle window reads the core chronicle (D471 D8, `IChronicle` from #75) instead of collecting events since the game started: a loaded save game shows its history, and `ChronicleBook.Sync` takes only what is new. Invented things are named in the display language (DE/EN) through `IRuntimeCatalog`; `first_use` finds the name through the placed object's type. The unused `GameScreen.InventionName` hook is gone.

### Fixed

- AI service: `POST /phase` with a lower tick and another phase is applied (loading an older save turns the clock back; only the same phase is ignored); a model larger than the VRAM budget fails its job as not retryable, so the core falls back at once (review #82).
- The start favour of a new world is a command in the log (`start_favor`, only before the first tick), so a replay from seed and log starts with the same favour (GW1 review #67 N1).
- The UI theme (frames, fonts, colours, text size, high contrast) reaches the game screen and the main menu: Godot does not pass a theme through a CanvasLayer, so both used the engine default theme; their UI roots are now bound to the current theme (`UiSetup.Bind`). Windows over the game sit in an overlay that stays visible in "watch only". The smoke checks that the card uses the theme's frame.
- Loading a save game never changes the file: empty or foreign files are refused read-only, older versions are migrated in a temporary copy (review GW3 #50 K2).
